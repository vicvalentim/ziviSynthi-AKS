# ziviSynthi AKS 3.9.5

[English](#english)

Versão para **M‑VAVE SMK‑37 Pro** na base fm1-base + felucca-bsp. Identidade USB `SMK-37 Pro_99400`.

- 128 presets de instrumento e quatro efeitos USB. Recalibração estéreo de 49 patches de fábrica.
- Perfil DSP AKS para envoltória, mola e sensibilidade de CV, com opção de perfil legado.
- Sincronização USB bidirecional de controles, pinos, painel, KS, SEQ, ARP, SCALE e roteamento.
- Editor HTML autônomo, compilação reproduzível do FWSC e fontes correspondentes da base em arquivo separado.

Foram verificados o simulador, os limites de flash e memória, a paridade DSP e o fluxo de atualização emulado. A instalação física, a saída analógica e o Bluetooth precisam de aferição nesta versão.

## English

Pre-release for the **M‑VAVE SMK‑37 Pro**, built on fm1-base and felucca-bsp. USB identity `SMK-37 Pro_99400`.

- 128 instrument presets and four USB effects. Stereo levels recalibrated on 49 factory patches.
- AKS DSP profile for the envelope, spring and CV sensitivity, with an optional legacy profile.
- Two-way USB sync for controls, pins, panel settings, KS, SEQ, ARP, SCALE and routing.
- Standalone HTML editor, reproducible FWSC and a separate archive with corresponding base sources.

Host verification covers the simulator, flash and memory limits, DSP parity and the emulated updater. Flashing, analog output and Bluetooth still require testing on this release.
