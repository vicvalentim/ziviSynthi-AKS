# ziviSynthi AKS 3.9.7 · Pre-release

**M‑VAVE SMK‑37 Pro · Felucca · USB identity `SMK-37 Pro_99600`.**

- **Try and Patch Matrix.** Load any of the 128 instrument presets and four USB FX patches in the browser. USB FX can process a local audio file. Instant Patchers provide a shortcut to selected sounds and sequences.
- **KS and SEQ.** Saved or loaded SEQ patterns can play in KS with their rests, note lengths and legato. KS event editing supports note, timing, velocity and attack, plus JSON import and export.
- **English and Portuguese.** Switch languages in Web Studio and use either standalone HTML offline. The site includes an animated Synthi illustration, firmware screens and updated guides.
- **Firmware.** The Felucca build has the 3.9.7 LCD version and a new USB identity. The FWSC, flash layout and updater were checked by automated tests. This exact build awaits a physical flash test.

Try the instrument in [Web Studio](https://vicvalentim.github.io/ziviSynthi-AKS/studio/#try). For installation and rollback, see the [installation guide](https://vicvalentim.github.io/ziviSynthi-AKS/docs/usage/INSTALL.en.html).

## Português

**M‑VAVE SMK‑37 Pro · Felucca · identidade USB `SMK-37 Pro_99600`.**

- **Try e Patch Matrix.** Carregue os 128 timbres e os quatro patches USB FX no navegador. Os efeitos USB aceitam um arquivo de áudio local. Os Instant Patchers dão acesso direto a timbres e sequências selecionados.
- **KS e SEQ.** Sequências salvas ou carregadas no SEQ podem tocar no KS com suas pausas, durações e legato. A edição do KS permite ajustar nota, tempo, velocidade e ataque de cada evento, além de importar e exportar frases em JSON.
- **Português e inglês.** O Web Studio tem seletor de idioma e dois HTMLs autônomos para uso offline. O site inclui a ilustração animada do Synthi, telas do firmware e novos guias.
- **Firmware.** A compilação Felucca traz a identificação 3.9.7 no LCD e uma nova identidade USB. O pacote FWSC, o mapa de flash e o instalador passaram por testes automatizados. A gravação desta compilação no teclado físico está pendente.

[Experimente no Web Studio](https://vicvalentim.github.io/ziviSynthi-AKS/pt/studio/#try) ou consulte o [guia de instalação e reversão](https://vicvalentim.github.io/ziviSynthi-AKS/pt/docs/usage/INSTALL.html).
