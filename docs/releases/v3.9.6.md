# ziviSynthi AKS 3.9.6 · Pre-release

**For the M‑VAVE SMK‑37 Pro.** USB identity `SMK-37 Pro_99500`.

ziviSynthi AKS is an independent digital interpretation of the EMS Synthi AKS. It brings pin-matrix patching and a KS-inspired keyboard sequencer to the SMK‑37 Pro and to Web Studio.

- Redesigned boot screen with a clearer wordmark and an animated 16 × 16 patch matrix.
- English and Portuguese site with saved language and theme preferences, an animated Synthi illustration, scalable firmware screens and a historical guide.
- 128 instrument patches, four USB effects, three oscillators, resonant filtering, ring modulation, envelope shaping and digital spring-style reverb.
- Web Studio offers local playback and patch editing, plus bidirectional control of a compatible Pro over USB MIDI. The Patch Matrix includes a shortcut for the active hardware patch and the Pro’s occupied USER slots. Local playback is also available in the downloadable HTML.

**Try first.** Open [Web Studio](https://vicvalentim.github.io/ziviSynthi-AKS/studio/#try) to play without hardware. Before flashing, read the [installation guide](https://vicvalentim.github.io/ziviSynthi-AKS/docs/usage/INSTALL.en.html) and back up patches you want to keep. The installer verifies the model and the approved firmware hash.

## Português

Pré-release para o **M‑VAVE SMK‑37 Pro**, com identidade USB `SMK-37 Pro_99500`. A abertura agora tem uma matriz 16 × 16 animada e tipografia mais legível. A página em inglês e português memoriza idioma e tema, reúne uma ilustração animada do Synthi, telas vetoriais do firmware e a história do instrumento. No Web Studio, a Patch Matrix abre diretamente o patch ativo ou os slots USER ocupados do teclado. A emulação inclui 128 timbres de instrumento e quatro efeitos USB.

[Experimente no navegador](https://vicvalentim.github.io/ziviSynthi-AKS/pt/studio/#try) ou leia o [guia de instalação](https://vicvalentim.github.io/ziviSynthi-AKS/docs/usage/INSTALL.html).
