# ziviSynthi AKS · User guide

Use ziviSynthi AKS as a browser instrument or install firmware 3.9.7 on the M‑VAVE SMK‑37 Pro. The same approach to sound design applies in both places. Choose a source, connect it to a destination on the 16 × 16 pin matrix, and save the result as a patch.

## Start in Web Studio

1. Open [Web Studio](https://vicvalentim.github.io/ziviSynthi-AKS/studio/#try) and select **Try Web Studio** to enable sound.
2. Play the onscreen keys with a mouse or by touch, or use **A W S E D F T G Y H U J K**.
3. Choose a factory preset, change a pin or knob, and export the active patch as JSON. In **Instant Patchers**, choose **Prestopatch Keyboard** or **On the Run** to start a KS phrase immediately. In **Edit KS phrase**, change event times, notes, velocity and attacks, then apply or export the phrase.
4. In **Patch Matrix**, use **SMK preset** to load any of the 128 instrument presets or four **USB FX** patches from the firmware. To hear a USB FX patch in Try, choose an audio file and select **Play file**.

## Connect the SMK‑37 Pro

1. Follow the [installation and recovery guide](usage/INSTALL.en.md) if the Pro needs the firmware. Back up personal patches and sequences before writing the firmware.
2. Connect the Pro by USB, open Web Studio in Chrome or Edge, grant USB MIDI access and select the Pro input and output ports.
3. Load the current patch from the Pro to begin with the instrument’s state, or apply the browser patch to begin with what is open in Studio. Live editing then exchanges changes in both directions.

On the controller, **K4** in Overview changes the preset. **GLOBE** opens modules, **PATCH** opens banks, and **PITCH** and **MOD** act as **Stick X** and **Stick Y**. **SEQ** opens the step editor, **ARP** the arpeggiator, and **SCALE** the key and scale controls.
